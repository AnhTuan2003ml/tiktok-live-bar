CACH TAO FILE CAI DAT TISO

1. Build game Windows:
   - Cai dung Unity theo ProjectVersion.txt
   - Chay build.bat
   - Kiem tra da co Build\TISO.exe

2. Chuan bi server:
   - Cai Node.js 20+
   - Mo TikTokBridge, chay npm ci neu can

3. Cai Inno Setup 6 tren Windows.

4. Chay installer\build-installer.bat
   - Ket qua: dist\TISO_Live_Control_Setup.exe

Installer se:
- Cho phep chon thu muc cai dat
- Cai ca game Build\ va server TikTokBridge\ trong cung 1 thu muc
- Tao shortcut Start Menu va Desktop
- Co shortcut mo ban an cua so cmd neu can
