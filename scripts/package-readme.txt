TISO LIVE — GOI CHAY NGAY
=========================

CACH CHAY
1. Giai nen (hoac chep) toan bo thu muc nay ra o dia bat ky.
   Khong chay truc tiep ben trong file ZIP.
2. Nhap dup vao run.bat.
   Launcher se tu mo: TikTok Bridge (server) -> Game TISO -> Control Panel tren Edge.

GOI NAY DA CO SAN
- Build\            Game TISO da bien dich
- TikTokBridge\     Server Node + Control Panel (da kem thu vien, khong can npm install)
- runtime
ode.exe  Node.js di kem, may dich khong can cai Node
- DJ_MUSIC\         Nhac nen (thay file MP3/WAV/OGG trong day de doi nhac)
- LiveAssets\       Anh nen san khau
- Documentation\    Tai lieu huong dan

CAN LAM TREN MAY MOI
- OBS: mo tab OBS trong Control Panel, nhap dia chi 127.0.0.1, port 4455 va mat khau
  OBS WebSocket cua may do (mat khau khong duoc mang theo trong goi).
- TikTok: dan link phien LIVE hoac @username roi bam "Ket noi LIVE".

LUU Y
- Cong mac dinh la 3100. Neu cong bi chuong trinh khac chiem, launcher se bao va dung lai.
  Doi cong trong TikTokBridge\.env neu can.
- Windows 10/11 64-bit.
